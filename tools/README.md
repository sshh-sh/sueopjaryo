# tools — 정리에 쓴 스크립트 (2026-11-26)

목업 데이터(`../data.js`)와 시트 정리본(`../수업자료_정리본.csv`)을 만든 스크립트와 그때의 원본 데이터입니다.
이 폴더 안에서 실행합니다.

| 파일 | 역할 |
|---|---|
| `sheet.csv` | 진도표 탭 스냅샷 (관련 단원 판단용) |
| `tab2.csv` | 정리 전 수업자료 탭 (A 카테고리, B 소카테고리, C 주제, D URL) |
| `x6.json` | `6과학자료.xlsx`를 JSON으로 바꾼 것 |
| `xl2json.js` | 압축을 푼 xlsx 폴더 → JSON (셀 값 + 하이퍼링크) |
| `gen2.js` | 대주제 5개 재분류 + 관련 단원 판단 + 6과학자료 38개 추가 → `data.js` |
| `tocsv.js` | `data.js` → 구글 시트 가져오기용 CSV (빈칸 = 위와 같음) |

```powershell
node gen2.js ..\data.js
```

```powershell
node tocsv.js ..\data.js ..\수업자료_정리본.csv
```

주의: 지금은 **수업자료 탭이 정리본으로 바뀌었기** 때문에 `tab2.csv`(옛 구조)를 다시 받으면 안 됩니다.
앞으로는 앱이 새 구조(A 대주제 ~ G 영상길이)를 직접 읽습니다.
